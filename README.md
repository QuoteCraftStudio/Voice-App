## Overview

Voice Reader is a browser-based reading and speech interface for opening text, choosing a voice, and following along while listening. The repository also retains a separate VoiceReader.html variant and QuickQuote.html.

## Highlights

- Open or paste text for reading.
- Choose an available speech voice and playback speed.
- Follow the text as it is spoken, with reading controls.
- Use the in-app library and appearance options where available.

## Get started

Open [`index.html`](./index.html) in a compatible browser to explore the source application. This is a web project; an installer is not supplied by GitHub Releases here.

> **Compatibility:** Speech voices and playback behavior depend on the browser and operating system. The two Voice Reader HTML files may differ; the main entry point is `index.html`.
